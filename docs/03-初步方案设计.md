## §1 总体架构

```
浏览器（dsh Web 客户端）                                 数据/网络
┌──────────────────────────────────────────────┐
│  conversation.view 槽位（对话/轨迹/熊猫日历…） │
│   ┌────────────────────────────────────────┐  │
│   │ 熊猫日历视图（HTML 富组件，React 手写）   │  │
│   │  · 今日信息卡   · 月历网格   · 日期详情    │  │
│   │  · 天气栏(多城市) · 命令:卡片写入对话      │  │
│   └──────────────────┬─────────────────────┘  │
│                      │ 调用                    │
│   ┌──────────────────▼─────────────────────┐  │
│   │          纯前端数据层（可注入/可测）        │  │
│   │ ① CalendarCore 本地历法引擎(无网络)        │  │
│   │   公农历互转/干支/生肖/节气/传统节日/国际节日 │  │
│   │ ② StatutoryLayer 法定节假日(网络+兜底)      │  │
│   │   holiday-cn: jsDelivr→GitHub raw→快照    │  │
│   │ ③ WeatherLayer 天气+定位(网络+缓存)         │  │
│   │   Open-Meteo / geolocation / ip-api       │  │
│   │   多城市存储(localStorage) + 限速+降级      │  │
│   └──────────────────┬─────────────────────┘  │
└──────────────────────┼───────────────────────┘
                       │ fetch（CORS 全开，无 key）
        ┌──────────────┼────────────────┐
        ▼              ▼                ▼
   holiday-cn JSON  Open-Meteo       BigDataCloud/
   (jsDelivr/raw)   天气+地理编码      ip-api(定位兜底)
```

**设计原则（沿用 dsh-chinese-poetry 已验证模式）**：
1. **宿主半部空转**：`lib/index.js` 提供 `apply(){}` 空实现（纯前端插件，无后端）。
2. **数据层纯函数 + 依赖注入**：fetch/存储/时钟/`Solar`引擎全部可注入 → `node --test` 单元测试（对齐诗词插件 PoetryDataLayer 的可测模式）。
3. **本地优先 + 多源回退 + 缓存降级**：断网时农历/节日/今日卡仍可用；法定节假日回退快照；天气显示上次缓存并提示。
4. **免构建手写 bundle**：单文件 `lib/client.js`，经 `window.__ModuleLoader__.load` 注册，locale 随 dsh UI（zh/en）。

## §2 技术选型

| 层 | 选型 | 理由 |
| --- | --- | --- |
| 插件宿主 | 同 dsh-chinese-poetry 结构（package.json `dsh.client` 声明 + cordis.patch.yml） | 生态内已验证的 web 客户端插件标准形态 |
| 视图注册 | `ctx.slots.inject("conversation.view", …)`，id `panda-calendar`，order 建议 30（对话 0 / 轨迹 10 / 诗词 20 之后） | 与对话/轨迹同级标签页 |
| UI | React 手写 JSX 风格元素 + 注入 `<style>` 的 CSS（对齐诗词插件） | 无构建步骤，HTML 富组件 |
| 农历引擎 | 内嵌 MIT 农历算法（参考 6tail/lunar-javascript，随包携带并声明来源） | 无网络依赖；公农历/干支/生肖/节气本地可算 |
| 节日规则 | 本地规则表：中国传统节日（农历月日/节气）+ 国际通用节日（固定日/复活节算法/第 N 个周几） | 无网络 |
| 法定节假日 | holiday-cn 年度 JSON（jsDelivr → GitHub raw → 内置快照） | 免费无 key、含调休、CORS 全开（实测） |
| 天气 | Open-Meteo forecast API（current + daily 3 天） | 免费无 key、实测 CORS `*` |
| 城市搜索/反查 | Open-Meteo Geocoding（`language=zh`）；BigDataCloud 反查（经纬度→城市名）；ip-api.com（IP 兜底） | 全免费无 key |
| 存储 | localStorage（城市列表、天气缓存、法定节假日年度缓存、UI 偏好） | 纯本地、免后端 |
| 测试 | `node --test "test/*.test.mjs"`；数据层注入 fetch/storage/timer | 对齐诗词插件 |

## §3 核心模块设计

### 3.1 CalendarCore —— 本地历法引擎（纯函数，无网络）

```
calendarCore(year, month, day, opts) / forToday(now, tzPolicy)
  → {
      solar:  { y,m,d, weekday, 农历标签(闰月) },
      lunar:  { 月日(如"八月十五"/"闰二月初二"), 干支年/月/日, 生肖(按春节换年),
                节气(若当日为节气，如"秋分") },
      festivals: [ {id, nameZh, nameEn?, kind: 'traditional'|'international'|'solarTerm'} ],
    }
```

- 时区口径（A6）：把用户本地 `now` 先换算为**北京时间日期**（`Asia/Shanghai`），农历/干支/生肖/节气/传统节日按该日期计算；公历展示与月历网格按本地日期。
- 干支/生肖按**春节**换年（A15/Q15 答案）。
- 中国传统节日：内置规则表（春节/元宵/龙抬头/清明〔节气〕/端午/七夕/中元/中秋/重阳/腊八/小年等），含中文名与英文译名。
- 国际通用节日：内置规则表——固定日（元旦 1/1、情人节 2/14、圣诞节 12/25 等）+ 算法日（复活节按格里历计算法、感恩节 11 月第 4 个周四、母亲节 5 月第 2 个周日、父亲节 6 月第 3 个周日等），中文名 + 英文名。
- 范围钉死：用测试固定 1900–2100 关键样例（含闰月、节气、春节跨界）。

### 3.2 StatutoryLayer —— 法定节假日（网络 + 兜底）

```
getYear(year): Promise<YearPlan>
  priority chain:
    1) localStorage 缓存（年度文件几乎不变 → 缓存 7 天或手动刷新覆盖）
    2) https://cdn.jsdelivr.net/gh/NateScarlet/holiday-cn@master/{year}.json
    3) https://raw.githubusercontent.com/NateScarlet/holiday-cn/master/{year}.json
    4) 内置快照（随插件发布最近 1–2 个完整年 + 当年规则兜底）
  返回: { year, days:[{name,date,isOffDay}] , papers[], from:'cache'|'cdn'|'raw'|'snapshot' }
```

- **放假/调休判定**：`isOffDay:true` → 放假（红）；`isOffDay:false` 且 name 为法定节假日 → 调休上班日（灰/「班」标记）；今日信息卡直接显示「放假/上班」结论。
- **未公布年份**（如当前 2027 尚空）：按 A5 用内置规则表仅标法定节日本身 + 「以官方公布为准」提示，并提供「刷新」按钮。
- 限速：年度数据为低频请求，仍套用轻量令牌桶（对齐诗词 429 退避模式），失败静默降级。
- 致谢：README + 视图角落标注数据来源 holiday-cn 与官方公告 papers 链接。

### 3.3 WeatherLayer —— 天气 + 定位（网络 + 缓存）

```
locate(): 优先链
  1) navigator.geolocation（用户授权）→ [lat,lon]
  2) ip-api.com/json（失败时）→ 城市 + 近似坐标（仅 http；dsh 本地 http 页无混合内容问题）
  3) 手动城市搜索（Open-Meteo Geocoding, language=zh）→ 列表带 国家/地区 消歧（如"东京"）
  失败 → 明确提示并保留上次缓存城市

getWeather(city):  Open-Meteo /v1/forecast?latitude&longitude&current=…&daily=…&forecast_days=3&timezone=auto
  current: 温度/体感/湿度/风速/天气代码(WMO→中文文案+图标emoji)
  daily ×3: 最高/最低温/天气代码（可选日出日落）
  缓存: 每城市 current 15min / daily 当日；失败回退缓存并标注时间

CityStore(localStorage): { id, name, country, lat, lon, timezone, source:'geo'|'ip'|'search'|'manual' }[]
  - 「我的位置」条目 + 常用城市列表（增/删/切换/设为默认）
```

### 3.4 视图与交互（conversation.view，HTML 富组件）

- **今日信息卡**（视图顶部）：本地公历（周几/农历按北京）、干支·生肖、节气、节日（中文主 + 英文副）、法定放假/上班徽标、当前城市天气（温度/体感/现象/图标）+ 未来 3 天小条。
- **月历网格**：当月 6×7 格；每格显示 公历日 + 农历小字；**红点/红字** = 节日/法定放假；**灰「班」** = 调休上班；**节气**标记；今日高亮。支持翻月、回到今天、点击格子 → 底部日期详情（该日完整信息 + 「写入对话」）。
- **城市天气栏**：城市选择器（搜索+消歧列表）、常用城市切换、「我的位置」；天气卡显示 实时概况 + 3 天预报。
- **对话命令（一期 A）**：任意卡片上的「发送到对话」→ 用 `props.inputActions.setDraft(markdown卡片)` 预填输入框 + 切到对话视图（用户回车即发；**不自动提交**，与诗词 AI 解读一致）。
- **i18n**：`ctx.locale.register(NS,{zh,en})`，节日名英文按需显示。
- **主题适配**：用 dsh 的 CSS 变量（如 `--dsw-*`），自动适配深浅色与主题插件。

### 3.5 今日信息卡 Markdown 样例（供「发送到对话」）

📅 2026-09-03 周四 · 农历七月廿二 丙午年(马) 乙未月 丁巳日

🏮 节日：—（距中秋还有 22 天）
