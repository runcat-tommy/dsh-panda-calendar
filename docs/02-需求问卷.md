# 熊猫日历（dsh-panda-calendar）需求问卷

> 问卷执行：2026-09。本文件记录问卷题目、选项与**最终选定答案**（含补充说明），作为方案设计的输入。🚩 记号 = 用户自定义补充内容。

---

## 第一部分：产品形态

### Q1 插件第一版以什么形态提供给用户？（单选）

- A. 命令 + 可视化都要
- B. 查询命令型：对话内返回结果
- C. 可视化面板型：Web GUI 常驻日历页
- D. 先做其一，后续再加

**✅ 答案：A（命令 + 可视化都要）**

### Q2 可视化形态的呈现位置与渲染方式

**🚩 用户补充（重要）：** 希望做成与 dsh 中「对话」「轨迹」**同级的视图**，放在相同位置（会话页头标签栏）；内容以 **HTML 富组件**为主（若 HTML 富组件实现不了，再考虑其他形式）。

> 结论：即注册 `conversation.view` 槽位（与 dsh-chinese-poetry 的「诗词」标签同机制），做原生 HTML 富组件视图，而非对话内纯文本/Markdown 卡片。

## 第二部分：日历内容范围

### Q3 农历深度（单选）

- A. 基础版：农历月日 + 生肖 + 节气
- B. **进阶版：再加干支纪年/月/日等（含生肖）** ✅
- C. 完整黄历版：宜忌、冲煞、吉神方位等

**✅ 答案：B（进阶版）** —— 本次不做老黄历宜忌（C 列为后续扩展）。

### Q4 「常见的外国节假日」指哪些？（可多选）

- A. 国际通用节日（情人节/母亲节/万圣节/感恩节/圣诞节等）
- B. 北美（美/加）
- C. 欧洲主要国家（英/法/德等）
- D. 东亚邻国（日/韩等）
- E. 第一版不做外国节日

**✅ 答案：A（国际通用节日）** —— 做全球广泛流行的节日，且本地规则可算（复活节/感恩节等均有算法），不做国别公共假日体系（B/C/D 不选）。

### Q5 中国法定节假日数据形态（单选）

**🚩 用户补充：** 找网上有没有公开的接口，类似 <https://timor.tech/api/holiday> 这类接口。

**✅ 结论：官方安排驱动（放假 + 调休完整呈现），走公开接口/公开数据。** 可行性调查结论（见 01 报告 §2.2）：timor.tech 服务器实测 403，**改用同源数据 [holiday-cn](https://github.com/NateScarlet/holiday-cn) 年度 JSON**（jsDelivr CDN 主 / GitHub raw 备 / 内置快照兜底），字段含 `isOffDay`（调休上班日可识别）。

### Q6 语言策略（单选）

- A. 中文为主，外国节日附英文名
- B. 中英双语并排
- C. 纯中文

**✅ 答案：A（中文为主，外国节日附英文名）** —— 界面文案仍随 dsh UI 语言做 zh/en 双语（沿用诗词插件模式）。

### Q7 海外用户时区口径（单选）

- A. 按北京时间定农历/节气，公历与天气随本地
- B. 做成可配置项
- C. 完全跟随用户本地时区

**✅ 答案：A（农历/节气/生肖/干支按北京时间换日，其余随本地）**

## 第三部分：天气功能

### Q8 天气位置来源（单选）

- A. 手动搜索/选择城市为主
- B. **自动定位 + 手动兜底** ✅
- C. 固定常用城市点选

**✅ 答案：B** —— 定位链：浏览器定位（授权）→ IP 兜底（ip-api.com）→ 失败则手动搜索城市（Open-Meteo Geocoding）。

### Q9 天气展示内容（可多选）

- A. 实时概况：温度/体感/天气现象 ✅
- B. 未来 3 天预报 ✅
- C. 未来 7 天预报
- D. 湿度/风速/气压等细项
- E. 日出日落时间
- F. 空气质量 AQI

**✅ 答案：A + B**（实时概况 + 未来 3 天）。D/E 视 Open-Meteo 顺带返回情况可低优先级附带，F 不做。

### Q10 城市管理（单选）

- A. **支持常用城市列表，可增删切换** ✅
- B. 单城市即可

**✅ 答案：A** —— 适配全球华人「家乡 + 现居地」场景，城市与天气结果存 localStorage。

### Q11 无 API key 约束（单选）

- A. 软性：默认无 key，个别功能可放宽
- B. **硬性：任何数据源都不要 key** ✅

**✅ 答案：B（硬性）** —— 可行性调查确认全部链路可无 key 实现。

## 第四部分：查询与展示能力

### Q12 需要哪些查询/展示能力？（可多选）

- A. 今日信息卡 ✅
- B. 任意日期查询（农历↔公历互转等）
- C. 全年总览
- D. 节日倒计时
- E. 天气详情

**✅ 答案：A（今日信息卡）**。补充追问确认视图内容范围后扩展为：**今日卡 + 月历视图**（Q13）。

### Q13（追问）视图主界面内容（单选）

- A. **今日卡 + 月历视图** ✅
- B. 只要今日信息卡
- C. 今日卡 + 月历 + 全年节假日总览子页签

**✅ 答案：A** —— 顶部今日信息卡 + 当月月历网格（每格标农历/节日/节气/法定假日与调休，可翻月），点日期可看该日详情（覆盖"任意日期查询"的轻量形态）。C 列为二期候选。

### Q14（追问）「对话命令」形态（单选）

- A. **A 现在做 + B 列为二期** ✅
- B. 只要 A：预填式卡片命令（视图内查询 + 一键把今日/任意日期卡片写入对话输入框，回车发送）
- C. 只要 B：宿主侧自然语言问答工具

**✅ 答案：A** —— 一期交付纯前端「卡片命令」（沿用诗词插件 `inputActions.setDraft` + 切到对话视图的模式）；二期调研 DSH 宿主侧工具注册能力后决定是否做自然语言问答（可能需要主仓库配合，暂不承诺）。

### Q15（追问）干支/生肖换年口径（单选）

- A. **按春节换年** ✅（丙午年/马 自正月初一起）
- B. 按立春换年
- C. 两个口径都标注

**✅ 答案：A（按春节换年）** —— 与大众万年历一致。

## 汇总：关键结论清单

1. 形态 = `conversation.view` 槽位注册「熊猫日历」标签（与对话/轨迹同级，HTML 富组件）。
2. 内容 = 今日信息卡 + 月历视图；公历/农历/干支（进阶）/生肖/节气 + 中国传统节日 + 国际通用节日（中文为主、附英文）+ 中国法定节假日（含调休）。
3. 农历/节气/干支/生肖、传统节日、国际节日 → **本地算法**；法定节假日 → **holiday-cn 年度数据联网拉取 + 快照兜底**；天气 → **Open-Meteo + 自动定位（浏览器/IP）+ 手动兜底 + 常用城市**。
4. 时区：农历系按北京时间换日，公历与天气随本地。
5. 硬约束：全部数据源**免费、无 API Key**。
6. 语言：界面 zh/en（随 dsh UI），节日名中文为主附英文。
7. 「命令」一期 = 视图内查询 + 卡片写入对话输入框；二期才评估宿主侧自然语言问答。
