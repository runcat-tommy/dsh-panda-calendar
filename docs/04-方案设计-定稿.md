## 1. 一句话定义

面向**全球华人**的 dsh Web 客户端插件：在会话页头新增 **「熊猫日历」** 标签页（与「对话」「轨迹」「诗词」同级的 `conversation.view` 视图，HTML 富组件），提供 **今日信息卡 + 月历 + 法定节假日/调休 + 多城市天气**；全部数据源**免费、无 API Key**。

## 3. 架构与文件布局

```
dsh-panda-calendar/
├── package.json          # dsh.bundle.patch + dsh.client 声明（仿 dsh-chinese-poetry）
├── cordis.patch.yml      # profile 层 bundle patch
├── LICENSE               # MIT
├── lib/
│   ├── index.js          # node 半部（空 host：export function apply(){}）
│   ├── client.js         # 浏览器半部：ModuleLoader bundle（唯一实现文件，免构建）
│   └── vendor/lunar*.js  # 内嵌 MIT 农历引擎（注明来源，MIT License）
├── test/                 # node --test（eval bundle + 注入 fetch/storage/react stub）
├── docs/                 # 01 可行性 / 02 问卷 / 03 初案 / 04 本定稿
└── README.md|.en.md / CHANGELOG.md
```

**浏览器半部结构（lib/client.js，单文件、无构建步骤，照搬诗词插件模式）**：
1. `window.__ModuleLoader__.load({ id:"dsh-panda-calendar", factory: (require) => { … } })`
2. factory 内：`var React = require("react")`；声明 `NS="pandaCalendar"`、`PLUGIN_VERSION`；zh/en 字典；**数据层类**（构造时注入 `fetchImpl/storage/now/waitImpl` 等）；视图函数（自写 `el()`/hooks 兼容）；CSS 字符串；`apply(ctx)`。
3. 导出：`exports.apply`、`exports.inject = ["slots","locale"]`，数据层类挂 `exports.*` 供 node 测试 eval 获取。

**视图注册（apply 内）**：
```js
ctx.slots.inject("conversation.view", function () {
  return ctx.slots.register({
    name: "conversation.view",
    id: "panda-calendar",
    order: 30,
    locale: NS,
    label: function () { return t("view"); },   // zh:"熊猫日历" en:"Panda Calendar"
  }, function (slotProps) {
    return el(PandaCalendarView, { t, sessionId: slotProps.sessionId, inputActions: slotProps.inputActions, layer: sharedLayer });
  });
});
```

## 4. 数据层设计（可注入、可单测）

### 4.1 CalendarCore（本地历法引擎，无网络）
- 农历引擎：内嵌 MIT 算法（参考 6tail/lunar-javascript，随包 vendor；功能点：公农历互转、干支年/月/日、生肖、节气）。
- 时区换算：`now → 北京时间日期`（`Asia/Shanghai`）→ 农历系全部按北京日计算；公历展示用本地日期。
- 中国传统节日规则表：春节/元宵/龙抬头/清明(节气)/端午/七夕/中元/中秋/重阳/腊八/小年等（zh + en 译名）。
- 国际通用节日规则表：元旦/情人节/复活节(算法)/母亲节(5月第2周日)/父亲节(6月第3周日)/万圣节/感恩节(11月第4周四)/平安夜/圣诞节等（zh + en）。
- 返回结构（某日）：
```ts
{ solar:{y,m,d,weekday,isLeapYear}, lunar:{monthCn,dayCn,month,day,leap,ganzhiYear,ganzhiMonth,ganzhiDay,zodiac,solarTerm?},
  festivals:[{id,nameZh,nameEn?,kind:'traditional'|'international'}], statutory?:{name,isOffDay} }
```

### 4.2 StatutoryLayer（法定节假日，网络+兜底）
```
fetchYear(year): 1) localStorage 缓存(7天) → 2) jsDelivr → 3) GitHub raw → 4) 内置快照(≤2年+规则表)
→ {year, days:[{name,date,isOffDay}], from:'cache'|'cdn'|'raw'|'snapshot'}
```
- 视图用：月历格「红=放假 / 灰班=调休上班 / 节日名」；今日卡「🇨🇳 放假·春节(共8天)」。
- 失败不报错：回退快照/规则，UI 标注数据日期与来源；「刷新」按钮强制重拉。

### 4.3 WeatherLayer（天气+定位，网络+缓存）
```
locate():  1) navigator.geolocation(授权) → 2) ip-api.com/json(HTTP) → 3) 手动搜索
getWeather(city): Open-Meteo /v1/forecast?lat&lon&current=温度,体感,湿度,风速,weather_code&daily=max,min×3天&timezone=auto
CityStore(localStorage): 城市列表{id,name,country,lat,lon,timezone,source} + 默认城市
```
- 城市搜索：Open-Meteo Geocoding `language=zh`，结果列表必须带 `country`/`admin1`/`country_code` 徽标消歧（东京=🇯🇵东京都 vs 中国江苏东京村）。
- 缓存：城市列表永久；天气 current 15min / daily 当日；失败回退缓存 + 标注时间。

## 5. 视图与交互（M2 范围）

- **今日信息卡**：本地公历日期/周几 → 农历(北京时间口径标注) 干支·生肖 → 节气 → 节日(chips) → 🇨🇳 法定状态 → 🌤 天气(城市/温度/体感/现象/3天mini条) → 「发送到对话」。
- **月历网格**：6×7；格内 公历日 + 农历小字；标记：🔴 节日/放假、灰「班」调休、节气小字、今日描边；头部 年月 + ◀ ▶ + 「今天」；点格 → 底部详情卡（含发送到对话）。
- **城市天气栏**：默认城市天气卡 + 城市管理（搜索添加/删除/切换/我的位置）。
- **降级体验**：断网 → 日历/节日照常；法定节假日用快照并注明；天气用缓存或提示。
- **视觉**：CSS 变量跟随 dsh 主题（`var(--dsw-*)`），深浅色自适应。

## 7. 测试策略（沿用诗词插件）

- `node --test "test/*.test.mjs"`，读 `lib/client.js` 源码 → stub `window.__ModuleLoader__` → `eval` 取 exports。
- 数据层单测：注入 `fetchImpl/storage/now/waitImpl`，**零网络**、确定性（仿 `data-layer.test.mjs`）。
- client stub 测试：断言 apply/inject、注册 def（name/id/order/label）、DOM-less 优雅降级（仿 `client.stub.test.mjs`）。
- host 冒烟：`lib/index.js` 为无操作 host（仿 `host.test.mjs`）。

## 8. 风险与回退（摘要，详见 03 §5）

- timor.tech 403 → 已弃主链路（holiday-cn 主）。
- GitHub raw 国内可达性 → jsDelivr 主 + raw 备 + 内置快照。
- 农历引擎内嵌许可 → 用 MIT 实现并注明来源。
- 北京/本地换日边界 → 农历行标注「北京时间」。
- 城市重名 → 国家徽标消歧。
- 2027 数据未公布 → 快照 + 「以官方公布为准」+ 刷新按钮。
